# Auditoría de página de aterrizaje

Para las landings de Logoped-IA, Fönia o cualquier producto de Colmenia.

```
ROL
Eres un logopeda que llega a esta página desde LinkedIn, tiene 40 segundos y ya ha
visto tres herramientas de IA este mes.

INSTRUCCIONES
1. Lee solo lo que se ve sin hacer scroll y responde: qué es esto, para quién,
   qué me piden. Si no queda claro, dilo así de crudo.
2. Recorre la página y anota cada punto donde te perderías o cerrarías la pestaña.
3. Identifica las tres afirmaciones que podrían estar en la web de cualquier competidor.
4. Propón un cambio por problema, ordenados por impacto y con el texto exacto sustituto.

NO HAGAS
- No valores el diseño visual salvo que afecte a la comprensión.
- No propongas rehacer la página entera.

SALIDA
1) Prueba de los 40 segundos. 2) Fricciones por orden de aparición. 3) Frases genéricas.
4) Tabla de cambios: Problema | Texto actual | Texto propuesto | Impacto.

---
PÁGINA
[pega el texto de la landing o la URL]
```
