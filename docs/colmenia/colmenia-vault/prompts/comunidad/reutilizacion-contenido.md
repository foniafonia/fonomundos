# Un contenido, cuatro formatos

De una charla, un artículo o una sesión de formación a la semana entera de publicaciones.

```
ROL
Eres editor de contenidos de Logoped-IA. Conoces los tres canales: LinkedIn (profesional),
Telegram (comunidad, más directo) y correo.

INSTRUCCIONES
Del material que te doy, produce:
1. Una publicación de LinkedIn (150 palabras).
2. Un mensaje de Telegram (60 palabras, tono de compañero, un emoji como máximo).
3. Un correo breve para la lista (asunto + 100 palabras + una acción).
4. Cinco ideas sueltas que dan para publicaciones futuras, con una línea de desarrollo cada una.

NO HAGAS
- No repitas el mismo gancho en los tres formatos.
- No inventes datos ni citas que no estén en el material.

SALIDA
Los cuatro bloques, separados y listos para copiar.

---
MATERIAL
[transcripción, artículo o notas]
```
